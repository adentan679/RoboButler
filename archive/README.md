# Original Course Code

This folder preserves the original RoboButler navigation and gesture-controlled actuation code from UC San Diego ECE/MAE 148.

The active implementation lives in the repository root and [`software/`](../software/). It combines navigation, gesture recognition, Arduino actuation, camera handoff, safety interlocks, and return-to-navigation behavior under one supervisor.

This archive is retained only for source traceability and comparison with the active integrated implementation. See the [main README](../README.md) for the current project architecture and validation status.
